# Towards Attack-Resistant Aggregate Computing

This is the project repository for the experiments of the paper

* Casadei, Roberto, Alessandro Aldini, and Mirko Viroli. "Combining trust and aggregate computing." 15th Int. Workshop on Foundations of Coordination Languages and Self-Adaptative Systems (FOCLASA’17), Trento, 2017.

and its extension paper submitted to the Elsevier journal Science of Computer Programming (SCP) Special Issue "Foclasa 2017".
